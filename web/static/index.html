150 pictures as a ZIP

Upload a video. You get back a ZIP with 150 pictures taken from it: two photos side by side per picture, in the same order as the video. No video, no audio and no overlay — only the pictures. Everything happens on this server.

This page is hosted on Vercel, where the video job cannot run: Vercel functions cap uploads at 4.5 MB, do not include FFmpeg and stop after 300 seconds. Deploy Dockerfile.web on Render (the included render.yaml) or any Docker host to use the tool.

This server is password protected — your browser will ask for the password.
